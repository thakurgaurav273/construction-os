# Product Roadmap

> Product: SitePilot
>
> Version: 1.0
>
> Last Updated: July 2026

---

# Vision

SitePilot aims to become the operating system for construction companies.

The long-term vision is to provide a single platform where organizations can manage every aspect of construction projects-from planning and procurement to workforce, finance, reporting, and AI-powered decision making.

Rather than becoming another ERP, SitePilot should become the central workspace where every stakeholder collaborates.

---

# Product Strategy

The roadmap follows an iterative approach.

Each release should deliver a complete and usable improvement instead of partially implemented features.

Priority order:

```
Foundation

↓

Core Operations

↓

Automation

↓

AI

↓

Enterprise

↓

Platform
```

Every phase should be deployable to production.

---

# Guiding Principles

Every release should:

- Solve real customer problems
- Improve usability
- Reduce manual work
- Increase automation
- Preserve simplicity
- Avoid unnecessary complexity

# Enterprise Edition

Enterprise customers may require:

- SSO (SAML/OAuth)
- Active Directory
- Multi-region deployment
- Audit exports
- IP restrictions
- Data retention policies
- Advanced security controls
- White-labeling

These features are intentionally excluded from the MVP.

# Long-Term Vision (3–5 Years)

SitePilot should become the default operating platform for construction companies.

Organizations should be able to:

- Plan projects
- Manage procurement
- Track workforce
- Monitor finances
- Collaborate in real time
- Automate repetitive work
- Use AI for decision support

-all within a single, unified platform.

Every release should move the product closer to this vision while maintaining simplicity, reliability, and a high standard of user experience.
